# v0.1.1 Plan

## 目標

把目前已能跑通的 smoke 訓練流程，補齊成更穩定、可重跑、可比較的正式訓練與評測版本。

## 優先項目

1. 收斂正式訓練穩定性
   - 重新驗證 `train/training_config.json` 在 WSL2 + 8GB VRAM 的成功率
   - 補上常見 OOM / 版本不相容的排查說明

2. 強化 benchmark 品質
   - 擴充 `examples/coding_benchmark.example.jsonl`
   - 把目前過度依賴 substring 的檢查，逐步補成可執行測試

3. 提升資料集真實性
   - 擴充 `examples/coding_tasks_batch.example.jsonl` 的題型覆蓋
   - 降低 mock teacher 佔比，逐步接入真實 teacher API 批次生成

4. 改善訓練與評測可觀測性
   - 固定輸出訓練 summary
   - 固定輸出 teacher/base/student 對比報告到 `reports/`

## 可能的程式變更

- `train/run_qlora.py`: 補更多 runtime 訊息與錯誤說明
- `src/student_inference.py`: 區分 base / adapter / teacher 的輸出格式
- `src/metrics.py`: 加入可執行測試型 benchmark
- `examples/coding_benchmark.example.jsonl`: 增加案例數量

## 驗收標準

- 正式訓練能在目標 WSL2 環境穩定啟動
- 至少有一份可重跑的 comparison report
- benchmark 不只依賴字串包含規則
- repo 文件能引導新使用者從 setup 走到 smoke 與正式訓練
